# 5-Variable NNS Spectral Decomposition and DPM_nD Aggregation

This note gives a five-variable example of the NNS directional spectral decomposition
and then shows how the `DPM_nD` aggregation traces back to the full orthant
decomposition.

The first part demonstrates the exact decomposition:

```math
\Sigma
=
\Sigma_Q+\Sigma_W,
```

where `Sigma_Q` is the between-orthant covariance generated by conditional mean
displacements, and `Sigma_W` is the within-orthant residual covariance.

The second part shows how the NNS package functions:

```r
NNS::Co.LPM_nD(data, target, degree, norm)
NNS::Co.UPM_nD(data, target, degree, norm)
NNS::DPM_nD(data, target, degree, norm)
```

collapse the full `2^d` orthant partition into three observable aggregate states:

```math
\mathrm{CLPM}_{nD},
\qquad
\mathrm{CUPM}_{nD},
\qquad
\mathrm{DPM}_{nD}.
```

The point is not that `DPM_nD` replaces the full spectral decomposition. It does not.
The point is that it is exactly traceable to the full orthant decomposition as a
coarse three-state aggregation.

---

## 1. Setup

Generate `n = 10,000` observations from a five-dimensional distribution with
uniform pairwise correlation approximately equal to `0.5`.

```r
set.seed(2024)

n <- 10000
d <- 5

R <- matrix(0.5, d, d) + diag(0.5, d)
L <- chol(R)

Z <- matrix(rnorm(n * d), n, d) %*% L
colnames(Z) <- paste0("X", 1:d)
```

The component mean vector is used as the target:

```r
target <- colMeans(Z)
```

In the run reported below, the target vector was:

| Variable | Target |
|---|---:|
| X1 | -0.006349 |
| X2 | -0.004824 |
| X3 | -0.002800 |
| X4 | 0.004986 |
| X5 | 0.001181 |

## 2. Classical PCA

Compute the population-denominator covariance matrix and its eigensystem.

```r
mu    <- colMeans(Z)
Zc    <- sweep(Z, 2, mu)
Sigma <- crossprod(Zc) / n
pca   <- eigen(Sigma)

cat("Classical eigenvalues:\n")
print(round(pca$values, 6))

cat("\nClassical eigenvectors, first 2 columns:\n")
print(round(pca$vectors[, 1:2], 6))
```

The classical eigenvalues were:

| Component | Eigenvalue |
|---:|---:|
| PC1 | 2.965193 |
| PC2 | 0.510783 |
| PC3 | 0.499329 |
| PC4 | 0.493351 |
| PC5 | 0.488601 |

The first eigenvalue is much larger than the remaining four, consistent with a
strong common direction induced by the uniform correlation structure.

## 3. Mean-Split Orthant Partition

Partition each variable at its component mean. For five variables, the full
mean-split partition contains:

```math
2^5 = 32
```

possible orthants.

Each observation is encoded as a binary label according to which variables are
above their component means.

```r
above_mean <- sweep(Z, 2, mu, ">")

orthant_label <- apply(above_mean, 1, function(row) {
  sum(row * 2^(0:(d - 1)))
})

n_orthants <- length(unique(orthant_label))

cat("\nNumber of occupied orthants:", n_orthants, "out of", 2^d, "\n")
```

The run occupied all orthants:

```text
32 out of 32
```

This is the five-dimensional analogue of the bivariate quadrant partition.

---

## 4. Between-Within Orthant Decomposition

For each orthant `r`, compute:

- the empirical probability `p_r`;
- the conditional mean `m_r`;
- the centered displacement `u_r = m_r - mu`;
- the within-orthant covariance `Sigma_r`.

Then accumulate:

```math
\Sigma_Q
=
\sum_{r=1}^{2^d}p_r u_r u_r^\top,
```

and:

```math
\Sigma_W
=
\sum_{r=1}^{2^d}p_r\Sigma_r.
```

The full covariance identity is:

```math
\Sigma
=
\Sigma_Q+\Sigma_W.
```

In code:

```r
Sigma_Q <- matrix(0, d, d)
Sigma_W <- matrix(0, d, d)

for (lab in unique(orthant_label)) {
  mask <- orthant_label == lab
  n_r  <- sum(mask)
  p_r  <- n_r / n

  Zr      <- Z[mask, , drop = FALSE]
  m_r     <- colMeans(Zr)
  u_r     <- m_r - mu
  Sigma_r <- crossprod(sweep(Zr, 2, m_r)) / n_r

  Sigma_Q <- Sigma_Q + p_r * tcrossprod(u_r)
  Sigma_W <- Sigma_W + p_r * Sigma_r
}

Sigma_rec <- Sigma_Q + Sigma_W
```

Each orthant contributes a rank-one between-orthant primitive:

```math
B_r
=
p_r u_r u_r^\top.
```

If `u_r` is nonzero, then:

```math
B_r u_r
=
p_r\|u_r\|^2u_r.
```

So each centered orthant conditional mean is the nonzero eigenvector of its own
rank-one between-orthant contribution.

## 5. Covariance Recovery

The decomposition recovers the covariance matrix to floating-point precision.

```r
cat("\nMax absolute difference between original Sigma and Sigma_Q + Sigma_W:",
    max(abs(Sigma - Sigma_rec)), "\n")

cat("Are they identical?",
    all.equal(Sigma, Sigma_rec, tolerance = 1e-12), "\n")
```

The result was:

```text
Max absolute difference between original Sigma and Sigma_Q + Sigma_W: 3.330669e-15
Are they identical? TRUE
```

Thus:

```math
\Sigma
=
\Sigma_Q+\Sigma_W
```

holds numerically to machine precision.

## 6. Eigensystem Recovery

Diagonalize the recovered covariance matrix.

```r
pca_rec <- eigen(Sigma_rec)

cat("\nRecovered eigenvalues:\n")
print(round(pca_rec$values, 6))

cat("Difference, classical minus recovered:\n")
print(round(pca$values - pca_rec$values, 10))

for (j in 1:d) {
  if (sum(pca$vectors[, j] * pca_rec$vectors[, j]) < 0) {
    pca_rec$vectors[, j] <- -pca_rec$vectors[, j]
  }
}

cat("\nAbsolute difference in aligned eigenvectors, first 2:\n")
print(round(abs(pca$vectors[, 1:2] - pca_rec$vectors[, 1:2]), 10))
```

The recovered eigenvalues were:

| Component | Recovered Eigenvalue |
|---:|---:|
| PC1 | 2.965193 |
| PC2 | 0.510783 |
| PC3 | 0.499329 |
| PC4 | 0.493351 |
| PC5 | 0.488601 |

The eigenvalue differences were zero at displayed precision:

```text
0 0 0 0 0
```

After sign alignment, the displayed eigenvector differences were also zero.

This confirms:

```math
\{p_r,m_r,\Sigma_r\}_{r=1}^{2^d}
\longrightarrow
\Sigma
\longrightarrow
(\lambda_i,v_i).
```

The full orthant decomposition recovers the covariance matrix and therefore recovers
the classical PCA eigensystem.

## 7. Eigenvalue Attribution

Each classical eigenvalue decomposes into a between-orthant contribution and a
within-orthant contribution.

For unit eigenvector `v_i`:

```math
\lambda_i
=
v_i^\top\Sigma_Qv_i
+
v_i^\top\Sigma_Wv_i.
```

Using the orthant decomposition:

```math
\lambda_i
=
\sum_{r=1}^{2^d}p_r(v_i^\top u_r)^2
+
\sum_{r=1}^{2^d}p_rv_i^\top\Sigma_rv_i.
```

In code:

```r
attrib <- data.frame(
  eigenvalue = pca$values,
  between = NA_real_,
  within = NA_real_
)

for (i in seq_along(pca$values)) {
  v <- pca$vectors[, i]

  attrib$between[i] <- drop(t(v) %*% Sigma_Q %*% v)
  attrib$within[i]  <- drop(t(v) %*% Sigma_W %*% v)
}

attrib$total <- attrib$between + attrib$within
attrib$between_pct <- 100 * attrib$between / attrib$total

print(round(attrib, 6))
```

The result was:

| Component | Eigenvalue | Between | Within | Total | Between Percent |
|---:|---:|---:|---:|---:|---:|
| PC1 | 2.965193 | 2.439089 | 0.526104 | 2.965193 | 82.25735 |
| PC2 | 0.510783 | 0.243905 | 0.266878 | 0.510783 | 47.75114 |
| PC3 | 0.499329 | 0.241130 | 0.258199 | 0.499329 | 48.29081 |
| PC4 | 0.493351 | 0.237770 | 0.255581 | 0.493351 | 48.19483 |
| PC5 | 0.488601 | 0.235968 | 0.252633 | 0.488601 | 48.29467 |

The leading eigenvalue is mostly between-orthant:

```math
\frac{2.439089}{2.965193}
=
0.8225735.
```

So approximately 82.3 percent of PC1 is explained by separation among orthant
conditional means.

## 8. Orthant-Level Attribution of PC1

The between-orthant part of PC1 decomposes further into individual orthant
contributions:

```math
\lambda_{1,Q}
=
\sum_{r=1}^{2^d}p_r(v_1^\top u_r)^2.
```

In code:

```r
v1 <- pca$vectors[, 1]

orthant_contrib <- data.frame(
  orthant = unique(orthant_label),
  contribution = NA_real_
)

for (i in seq_along(orthant_contrib$orthant)) {
  lab  <- orthant_contrib$orthant[i]
  mask <- orthant_label == lab
  p_r  <- sum(mask) / n
  u_r  <- colMeans(Z[mask, , drop = FALSE]) - mu

  orthant_contrib$contribution[i] <- p_r * (sum(v1 * u_r))^2
}

cat("\nSum of orthant-level between contributions for PC1:",
    sum(orthant_contrib$contribution), "\n")

cat("Direct Sigma_Q between contribution for PC1:",
    attrib$between[1], "\n")
```

The result was:

```text
Sum of orthant-level between contributions for PC1: 2.439089
Direct Sigma_Q between contribution for PC1: 2.439089
```

The per-orthant contributions sum exactly to the Rayleigh quotient:

```math
v_1^\top\Sigma_Qv_1.
```

This is the full orthant-level spectral genealogy.

## 9. Converse Failure

The decomposition runs in one direction.

From the full orthant decomposition, one recovers the covariance matrix:

```math
\{p_r,m_r,\Sigma_r\}_{r=1}^{2^d}
\longrightarrow
\Sigma.
```

From the covariance matrix, one recovers the PCA eigensystem:

```math
\Sigma
\longrightarrow
(\lambda_i,v_i).
```

But PCA output alone does not recover the orthant probabilities, orthant assignments,
or orthant conditional means.

```r
cat("\nGiven only the eigenvalues and eigenvectors, can we recover the orthant means?\n")
cat("No. Example: conditional mean of most populated orthant is:\n")

lab_max <- names(which.max(table(orthant_label)))
print(round(colMeans(Z[orthant_label == lab_max, , drop = FALSE]), 6))

cat("This cannot be deduced from PCA output.\n")
```

The result was:

```text
Given only the eigenvalues and eigenvectors, can we recover the orthant means?
No. Example: conditional mean of most populated orthant is:
1.092094 1.088237 1.049830 1.084412 1.071189
This cannot be deduced from PCA output.
```

Therefore:

```math
\{p_r,m_r,\Sigma_r\}_{r=1}^{2^d}
\Rightarrow
\Sigma
\Rightarrow
(\lambda_i,v_i),
```

but:

```math
(\lambda_i,v_i)
\not\Rightarrow
\{p_r,m_r,\Sigma_r\}_{r=1}^{2^d}.
```

PCA is a downstream summary. The orthant decomposition contains strictly more
directional information.

---

## 10. Scaling to Higher Dimensions

The full orthant decomposition is exact, but it scales as:

```math
2^d.
```

For five variables:

```math
2^5 = 32.
```

For 50 variables:

```math
2^{50}
\approx
1.13\times 10^{15}.
```

That is not a practical partition to estimate directly. Most orthants would be empty
or too sparsely populated to support stable conditional mean and covariance estimates.

This motivates an aggregate n-dimensional partial moment summary.

---

## 11. DPM_nD as a Three-State Aggregation

The NNS n-dimensional partial moment functions collapse the full orthant partition
into three observable aggregate states:

```math
\mathrm{CLPM}_{nD}
=
\mathrm{all\ variables\ below\ target},
```

```math
\mathrm{CUPM}_{nD}
=
\mathrm{all\ variables\ above\ target},
```

```math
\mathrm{DPM}_{nD}
=
\mathrm{all\ mixed\ sign\ configurations}.
```

So the state count is reduced from:

```math
2^d
```

to:

```math
3.
```

For `d = 5`, the full partition has 32 orthants. The three-state aggregation is:

```math
G_L
=
\{0\},
```

```math
G_U
=
\{31\},
```

```math
G_D
=
\{1,2,\ldots,30\}.
```

Thus:

```math
\mathrm{CLPM}_{nD}
=
\sum_{r\in G_L}p_r,
```

```math
\mathrm{CUPM}_{nD}
=
\sum_{r\in G_U}p_r,
```

```math
\mathrm{DPM}_{nD}
=
\sum_{r\in G_D}p_r.
```

At degree zero, `DPM_nD` is not separate from the full orthant decomposition. It is
the coarse three-state projection of it.

## 12. DPM_nD R Example Using the NNS Package

The following example uses the exported NNS package functions directly.

The function signatures are:


### 12.1 Full Orthant Aggregation for Reference

```r
target <- colMeans(Z)

above_target <- sweep(Z, 2, target, ">")

orthant_label <- apply(above_target, 1, function(row) {
  sum(row * 2^(0:(d - 1)))
})

orthant_tab <- table(orthant_label)

p_all_lower <- as.numeric(orthant_tab[as.character(0)]) / n
p_all_upper <- as.numeric(orthant_tab[as.character(2^d - 1)]) / n

if (is.na(p_all_lower)) p_all_lower <- 0
if (is.na(p_all_upper)) p_all_upper <- 0

p_mixed <- 1 - p_all_lower - p_all_upper

orthant_aggregated <- c(
  CLPM_nD = p_all_lower,
  CUPM_nD = p_all_upper,
  DPM_nD  = p_mixed
)

print(round(orthant_aggregated, 6))
print(sum(orthant_aggregated))
```

The result was:

| `CUPM_nD` | 0.1663 |

```text
1
```

## 13. How DPM_nD Traces Back to the Full Decomposition

The full decomposition uses all 32 orthants.

At degree zero, the three NNS nD states are exactly group sums of the full orthant
probabilities:

```math
\mathrm{CLPM}_{nD}
=
p_0,
```

```math
\mathrm{CUPM}_{nD}
=
p_{31},
```

```math
\mathrm{DPM}_{nD}
=
\sum_{r=1}^{30}p_r.
```

In the run:

```math
p_0
=
0.1646,
```

```math
p_{31}
=
0.1663,
```

```math
\sum_{r=1}^{30}p_r
=
0.6691.
```

The NNS functions return exactly those values.

So the map is:

```math
\{p_r\}_{r=0}^{31}
\longrightarrow
(\mathrm{CLPM}_{nD},\mathrm{CUPM}_{nD},\mathrm{DPM}_{nD}).
```

This is an exact aggregation at degree zero.

However, the full spectral decomposition requires more than probabilities. It requires
each orthant displacement vector and each within-orthant covariance:

```math
\{p_r,u_r,\Sigma_r\}_{r=1}^{2^d}.
```

The full between-orthant covariance is:

```math
\Sigma_Q
=
\sum_{r=1}^{2^d}p_r u_r u_r^\top.
```

When the 30 mixed orthants are collapsed into a single `DPM_nD` value, their
individual displacement vectors are no longer separately retained. Therefore:

```math
\mathrm{full\ orthant\ decomposition}
\Rightarrow
(\mathrm{CLPM}_{nD},\mathrm{CUPM}_{nD},\mathrm{DPM}_{nD}),
```

but:

```math
(\mathrm{CLPM}_{nD},\mathrm{CUPM}_{nD},\mathrm{DPM}_{nD})
\not\Rightarrow
\mathrm{full\ orthant\ decomposition}.
```

This is the central tradeoff:

```math
\mathrm{full\ orthant\ decomposition}
=
\mathrm{exact\ but\ exponential},
```

while:

```math
\mathrm{DPM}_{nD}\ \mathrm{aggregation}
=
\mathrm{scalable\ but\ coarser}.
```

## 15. Final Summary

The full five-variable orthant decomposition proves the exact identity:

```math
\Sigma
=
\Sigma_Q+\Sigma_W.
```

It also recovers the classical PCA eigensystem to floating-point precision.

The NNS nD functions:

```r
NNS::Co.LPM_nD(Z, target, degree, norm)
NNS::Co.UPM_nD(Z, target, degree, norm)
NNS::DPM_nD(Z, target, degree, norm)
```

provide a three-state aggregation of the same mean-split geometry:

```math
2^d
\longrightarrow
3.
```

At degree zero, the connection to the full decomposition is exact at the probability
level:

```math
\mathrm{CLPM}_{nD}
=
p_{\mathrm{all\ lower}},
```

```math
\mathrm{CUPM}_{nD}
=
p_{\mathrm{all\ upper}},
```

```math
\mathrm{DPM}_{nD}
=
p_{\mathrm{all\ mixed}}.
```

At degree one, the same three states become severity-weighted directional mass
shares.

The result is a clean hierarchy:

```math
\mathrm{full\ orthant\ decomposition}
\Rightarrow
\mathrm{exact\ covariance\ and\ PCA\ recovery},
```

and:

```math
\mathrm{DPM}_{nD}
\Rightarrow
\mathrm{scalable\ three\ state\ directional\ summary}.
```

The two are complementary. The full orthant decomposition gives the complete spectral
genealogy. The `DPM_nD` aggregation gives a scalable high-dimensional summary that
is directly traceable to the same underlying mean-split geometry.

## Full R Code

```r
# =============================================================================
# 5-Variable NNS Spectral Decomposition and DPM_nD Aggregation
# =============================================================================

library(NNS)

set.seed(2024)

n <- 10000
d <- 5

# -----------------------------------------------------------------------------
# 1. Generate correlated five-dimensional data
# -----------------------------------------------------------------------------

R <- matrix(0.5, d, d) + diag(0.5, d)
L <- chol(R)

Z <- matrix(rnorm(n * d), n, d) %*% L
colnames(Z) <- paste0("X", 1:d)

target <- colMeans(Z)

cat("\nTarget vector, component means:\n")
print(round(target, 6))

# -----------------------------------------------------------------------------
# 2. Classical PCA
# -----------------------------------------------------------------------------

mu    <- colMeans(Z)
Zc    <- sweep(Z, 2, mu)
Sigma <- crossprod(Zc) / n
pca   <- eigen(Sigma)

cat("\nClassical eigenvalues:\n")
print(round(pca$values, 6))

cat("\nClassical eigenvectors, first 2 columns:\n")
print(round(pca$vectors[, 1:2], 6))

# -----------------------------------------------------------------------------
# 3. Full mean-split orthant partition
# -----------------------------------------------------------------------------

above_mean <- sweep(Z, 2, mu, ">")

orthant_label <- apply(above_mean, 1, function(row) {
  sum(row * 2^(0:(d - 1)))
})

cat("\nOccupied orthants:\n")
cat(length(unique(orthant_label)), "out of", 2^d, "\n")

# -----------------------------------------------------------------------------
# 4. Full between-within orthant decomposition
# -----------------------------------------------------------------------------

Sigma_Q <- matrix(0, d, d)
Sigma_W <- matrix(0, d, d)

for (lab in unique(orthant_label)) {
  mask <- orthant_label == lab
  n_r  <- sum(mask)
  p_r  <- n_r / n

  Zr      <- Z[mask, , drop = FALSE]
  m_r     <- colMeans(Zr)
  u_r     <- m_r - mu
  Sigma_r <- crossprod(sweep(Zr, 2, m_r)) / n_r

  Sigma_Q <- Sigma_Q + p_r * tcrossprod(u_r)
  Sigma_W <- Sigma_W + p_r * Sigma_r
}

Sigma_rec <- Sigma_Q + Sigma_W

cat("\nMax absolute difference between original Sigma and Sigma_Q + Sigma_W:\n")
print(max(abs(Sigma - Sigma_rec)))

cat("\nAre they identical to tolerance 1e-12?\n")
print(all.equal(Sigma, Sigma_rec, tolerance = 1e-12))

# -----------------------------------------------------------------------------
# 5. Eigensystem recovery
# -----------------------------------------------------------------------------

pca_rec <- eigen(Sigma_rec)

cat("\nRecovered eigenvalues:\n")
print(round(pca_rec$values, 6))

cat("\nDifference, classical minus recovered:\n")
print(round(pca$values - pca_rec$values, 10))

for (j in 1:d) {
  if (sum(pca$vectors[, j] * pca_rec$vectors[, j]) < 0) {
    pca_rec$vectors[, j] <- -pca_rec$vectors[, j]
  }
}

cat("\nAbsolute difference in aligned eigenvectors, first 2:\n")
print(round(abs(pca$vectors[, 1:2] - pca_rec$vectors[, 1:2]), 10))

# -----------------------------------------------------------------------------

  attrib$between[i] <- drop(t(v) %*% Sigma_Q %*% v)
  attrib$within[i]  <- drop(t(v) %*% Sigma_W %*% v)

  contribution = NA_real_

  mask <- orthant_label == lab
  p_r  <- sum(mask) / n
  u_r  <- colMeans(Z[mask, , drop = FALSE]) - mu
```
