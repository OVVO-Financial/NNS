2 NNS.VAR Example with 3 Variables: Fed Funds, Real GNP, and Inflation

Using the log differences of each Real GNP and Inflation, the previous method creates lowest frequency series. In this illustrative VAR example from Lutz Kilian1, Fed Funds (monthly) is averaged over 3-period windows to align with quarterly GNP data.

The series come from FRED: FEDFUNDS (effective federal funds rate, monthly, percent), GNPC96 (real gross national product, quarterly) and GNPDEF (GNP implicit price deflator, quarterly). The window, 1954 Q4 to 2007 Q4, is the archived page’s 213 quarters. Its interest rates are reproduced exactly; real growth and inflation differ slightly because FRED serves the current vintage of the national accounts.

3 Forecast 12 Quarters Out-of-Sample Using All Methods

We will withhold 12 quarters of observations as the test set. Let’s see how accurate a VAR, a random forest and NNS are…

Why a random forest? The Bank of England has recently been posting working papers utilizing machine learning, specifically random forests:

  • Machine Learning at Central Banks
  • Predicting Bank Distress in the UK with Machine Learning

Every method is fit and tuned on the training quarters. The tuning steps hold out the end of the training sample for internal validation; their scores choose settings and are reported as such. Only the final forecasts meet the test quarters.

5 NNS and Random Forest

5.1 Function to Generate Lagged Variables

The following code is to generate a matrix of lagged variables to be used in both NNS and Random Forest routines.

lag.mtx <- function(x, tau) {
  colheads <- NULL
  if (is.null(dim(x)[2])) {
    colheads <- noquote(as.character(deparse(substitute(x))))
    x <- t(t(x))
  }
  j.vectors <- list()
  for (j in 1:ncol(x)) {
    if (is.null(colheads)) {
      colheads <- colnames(x)[j]
      colheads <- noquote(as.character(deparse(substitute(colheads))))
    }
    x.vectors <- list()
    heads <- paste0(colheads, ".tau.")
    heads <- gsub("\"", "", heads)
    for (i in 0:tau) {
      x.vectors[[paste(heads, i, sep = "")]] <- numeric(0L)
      start <- tau - i + 1
      end <- length(x[, j]) - i
      x.vectors[[i + 1]] <- x[start:end, j]
    }
    j.vectors[[j]] <- do.call(cbind, x.vectors)
    colheads <- NULL
  }
  return(as.data.frame(do.call(cbind, j.vectors)))
}

6.2 Create Forecasted IVs Using NNS.ARMA()

Each series is forecast on its own. NNS.seas lists candidate periods, and NNS.ARMA.optim chooses among them on the last 2 * h training quarters.

nns_uni <- lapply(seq_len(ncol(y_train_VAR)), function(i) {
  variable <- y_train_VAR[, i]
  periods <- NNS.seas(variable, modulo = 4, mod.only = FALSE, plot = FALSE)$periods
  NNS.ARMA.optim(variable, h = h, seasonal.factor = periods,
                 training.set = length(variable) - 2 * h, ncores = 1,
                 print.trace = FALSE, obj.fn = expression(sum((predicted - actual)^2)),
                 objective = "min")
})
nns_IVs <- sapply(nns_uni, `[[`, "results")
colnames(nns_IVs) <- colnames(y)

7 Use Forecasted IVs in NNS and Random Forest

We will now utilize the forecasted variables in the multi-variate NNS.reg() function. Our first step is to pass these variables through the NNS.boost() function in order to reduce any unnecessary features. The objective function obj.fn and objective objective are set explicitly, since this is not a classification problem.

From there, we use the reduced variable set (if any reduction) in the NNS.stack() function which cross-validates the n.best and threshold parameters from the NNS.reg() function. Both tune on the last 2 * h rows of the lagged training matrix.

# Combine forecasted IVs onto training data.frame, then lag it
new_values <- rbind(y_train_VAR, nns_IVs)
lagged_new_values <- lag.mtx(new_values, tau = 4)
y_train_nns <- head(lagged_new_values, nrow(lagged_new_values) - h)
y_test_nns <- tail(lagged_new_values, h)

# Select tau = 0 as test set DVs
DVs <- which(grepl("tau.0", colnames(y_train_nns)))
nns_est <- rf_est <- list()
stack_validation <- matrix(NA, 3, 2, dimnames = list(colnames(y), c("Multivariate", "Dimension reduction")))

par(mfrow = c(3, 1), mar = c(4, 4, 1, 1))
for (i in DVs) {
  index <- which(DVs == i)
  # NNS.boost() is an ensemble method comparable to xgboost, and aids in dimension reduction
  nns_boost_est <- NNS.boost(IVs.train = y_train_nns[, -i], DV.train = y_train_nns[, i],
                             IVs.test = y_test_nns[, -i],
                             obj.fn = expression(sum((predicted - actual)^2)), objective = "min",
                             ts.test = 2 * h, learner.trials = 100, epochs = 100, type = NULL,
                             feature.importance = FALSE, folds = 1, status = FALSE)

  # NNS.stack() cross-validates the parameters of the multivariate NNS.reg()
  # and dimension reduction NNS.reg()
  relevant_vars <- colnames(y_train_nns) %in% names(nns_boost_est$feature.weights)
  nns_stack <- NNS.stack(IVs.train = y_train_nns[, relevant_vars], DV.train = y_train_nns[, i],
                         IVs.test = y_test_nns[, relevant_vars], folds = 1, ts.test = 2 * h,
                         order = "max", obj.fn = expression(sum((predicted - actual)^2)),
                         objective = "min", type = "REG", status = FALSE)
  stack_validation[index, ] <- sqrt(c(nns_stack$OBJfn.reg, nns_stack$OBJfn.dim.red) / (2 * h))

  # Ensemble with univariate estimates
  nns_est[[index]] <- (nns_IVs[, index] + nns_stack$stack) / 2

  # Random Forest
  set.seed(123)
  rf <- randomForest(y_train_nns[, -i], y_train_nns[, i], ntree = 100)
  rf_est[[index]] <- predict(rf, newdata = y_test_nns[, -i])

  # Plot all results
  plot(1:h, y_test_VAR[, index], type = "l", lwd = 3, ylim = range(y[, index]),
       xlab = "Forecast Period", ylab = colnames(y)[index])
  lines(1:h, nns_est[[index]], col = "red", lwd = 2)
  lines(1:h, rf_est[[index]], col = "green", lwd = 2)
  lines(1:h, VAR_fc[, index], col = "blue", lwd = 2)
  legend("topleft", col = c("black", "red", "blue", "green"),
         legend = c("Actual", "NNS", "VAR", "RF"), lty = 1, lwd = c(3, 2, 2, 2))
}

8 NNS.VAR()

The NNS.VAR() function now accomplishes all of the prior steps in a single line of code. By default (naive.weights = TRUE) its ensemble weights the univariate and multivariate forecasts equally.

NNS.VAR tunes on its own chronological holdout inside the training sample. With the default validation = "pipeline", the holdout’s lagged predictors are built from each series’ forecasts made at the holdout’s origin, as they would be in use, and only observed holdout values are scored.

Ranking the methods would need several forecast origins (rolling or expanding windows) with the same data, origins, horizon and tuning budget for every method. The internal validation tables above are the scores each NNS step optimized; they are not estimates of test accuracy.
